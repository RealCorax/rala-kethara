## How to Read This Document

Each page entry shows:
- **File name** (what the .md file will be called in Obsidian)
- **Furling name** | **Poetic translation** | **English reference**
- **CSS layout** (from archive-library.css)
- **Access level** (Visitor / Student / Citizen / Keeper / Council)
- **Type** (index / content / locked-entry etc.)
- Notes where relevant

**Layout classes available:**
- `archive-index` — Branch/section entrance, card grid, 900px wide
- `archive-content` — Standard knowledge record, single column, 680px (~80% of all pages)
- `archive-species` — Species or civilisation profile, floating card + body
- `archive-person` — Individual Furling profile, portrait centred, 660px
- `archive-data` — Data-heavy, wide tables, optional two-column, 820px
- `archive-gallery` — Image collections (arts branch)
- `archive-media` — Audio/video as primary content
- `archive-language` — Language reference, searchable
- `archive-interactive` — Embedded tools (periodic table, maps)

**Lock rule:** Every locked page still appears in the vault with its title visible and a Selavai message. It is not absent — it is held.
